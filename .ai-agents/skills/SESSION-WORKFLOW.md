# Session Workflow - PDF Utilities Extension

**Purpose**: Guide for managing multi-step work sessions on this project.

---

## Recommended Approach for Complex Tasks

1. Read [AGENTS.md](../../AGENTS.md) for full project context.
2. Read [QUICK-REFERENCE.md](../QUICK-REFERENCE.md) for the cheat sheet.
3. Inspect the owning file and nearby tests before editing.
4. Make one focused change at a time.
5. Run the narrowest relevant check first, then `npm run compile` and `npm test`.
6. Test in VS Code with `F5` when the change affects extension behavior.

## Session Notes

- Keep the current task narrow and explicit in commentary updates.
- If work is interrupted, record the last edited file and the next validation step.
- Do not widen scope until the current slice is validated.
