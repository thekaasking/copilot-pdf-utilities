1. Read [AGENTS.md](../../AGENTS.md) for full project context
2. Read [QUICK-REFERENCE.md](../QUICK-REFERENCE.md) for the cheat sheet
3. Run 
pm run compile to ensure the build is clean before starting
4. Make incremental changes and run 
pm test after each change to verify
5. Test in VS Code with F5 before packaging
